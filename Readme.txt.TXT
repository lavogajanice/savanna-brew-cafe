SAVANNA BREW CAFÉ WEBSITE

Project Description:
This project is a five-page café website developed using HTML5 and CSS3. The pages include Home, About, Menu, Gallery and Contact.

Technologies Used:
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design

Validation:
- All five HTML pages were tested using the W3C HTML Validator.
- The CSS stylesheet was tested using the W3C CSS Validator.
- Both HTML and CSS validation completed with zero errors.

Remaining Warnings:
No remaining validation errors or warnings were reported.
